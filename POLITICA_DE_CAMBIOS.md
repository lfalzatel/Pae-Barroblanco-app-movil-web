**FECHA DE VIGENCIA:** 6 de Febrero, 2026
**PROYECTO:** Sistema PAE Barroblanco (PWA)

---

## ⚠️ ADVERTENCIA IMPORTANTE

**NO SE ESTÁ AUTORIZADO A REALIZAR CAMBIOS EN EL DISEÑO, ESTRUCTURA O LÓGICA DE LAS PÁGINAS Y OBJETOS EXISTENTES SIN AUTORIZACIÓN EXPRESA.**

### 1. Prohibición de Modificaciones No Autorizadas
Cualquier intento de:
- Modificar estilos CSS/Tailwind existentes.
- Cambiar la estructura JSX/HTML de componentes ya aprobados.
- Alterar la lógica de negocio o funciones de base de datos.
- Eliminar o renombrar archivos.

**ESTÁ ESTRICTAMENTE PROHIBIDO** a menos que se solicite explícitamente por el administrador del proyecto o el usuario principal.

### 2. Procedimiento para Nuevos Desarrollos
Si se requiere una nueva funcionalidad:
1.  Se debe crear un **nuevo componente** o **nueva página** aislada.
2.  No se debe "reutilizar y romper" componentes existentes.
3.  Se debe solicitar aprobación antes de integrar cualquier cambio en la rama principal (`main`).

### 3. Integridad Visual
El diseño actual (Pixel Perfect) ha sido validado y aprobado. Cualquier desviación visual será considerada un error crítico y deberá ser revertida inmediatamente.

---

**Mantener la estabilidad y consistencia del sistema es prioridad absoluta.**
