# Manual de Usuario - Sistema PAE Barroblanco

## 1. Introducción
Bienvenido al sistema de gestión PAE. Este sistema permite el registro rápido de asistencia al Programa de Alimentación Escolar.

## 2. Acceso al Sistema
- Ingrese via web o instale la App (PWA) en su móvil.
- Use sus credenciales institucionales.

## 3. Roles
- **Administrador**: Gestión total (Sedes, Usuarios, Reportes Globales).
- **Docente/Encargado**: Registro de asistencia de su grupo asignado.

## 4. Guía Rápida: Tomar Asistencia
1. Seleccione la **Sede**.
2. Seleccione el **Grupo**.
3. Marque la asistencia (Recibió / No Recibió / Ausente).
4. Guarde los cambios.

## 5. Reportes
- Acceda a la pestaña "Reportes" para ver estadísticas y descargar Excel.
