# Cuadro Comparativo: Versión SENA vs. Versión Comercial

Este documento delimita el alcance de la versión académica entregada al SENA frente a la versión comercial (Obra Derivada Autónoma) propiedad del autor.

| Característica / Módulo | Versión Académica (Entrega SENA) | Versión Comercial (Propiedad del Autor) |
| :--- | :--- | :--- |
| **Propósito** | Evidencia de aprendizaje y cumple requisitos funcionales básicos de la institución. | Producto SaaS (Software as a Service) para venta y licenciamiento masivo. |
| **Plataforma de Pagos** | **No Incluida**. Gestión manual de cobros. | **Integración Total**. Pasarela de pagos (Bold, Wompi, PayU) para recargas en línea. |
| **Geolocalización (Rutas)** | **No Incluida**. | **GPS en Tiempo Real**. Rastreo de rutas escolares y notificaciones de cercanía. |
| **App para Padres** | Acceso Web Responsive (PWA básica). | **App Nativa (iOS/Android)** con notificaciones push avanzadas y billetera digital. |
| **Gestión de Stock** | Inventario básico. | **IA Predictiva**. Sugerencias de compras basadas en consumo histórico y mermas. |
| **Soporte Técnico** | Documentación de entrega. | **Soporte SLA 24/7**. Mesa de ayuda y actualizaciones automáticas. |
| **Infraestructura** | Despliegue gratuito (Vercel Hobby / Supabase Free). | **Cloud Dedicado**. AWS/GCP con escalabilidad automática y backups georedundantes. |
| **Autenticación** | Correo/Contraseña y Login Google básico. | **Biometría Avanzada** (FaceID/Huella) y SSO Corporativo. |

---

## Nota Legal
Las funcionalidades listadas en la columna "Versión Comercial" constituyen un desarrollo independiente, realizado con recursos propios y fuera del tiempo de formación académica, configurando una obra derivada autónoma sobre la cual el SENA no posee derechos patrimoniales.
